# San Veridia Vice

An original top-down 2D open-world crime action game set in the sun-soaked coastal city of **San Veridia**. Explore the sun-drenched streets on foot or steal fast cars (`Vipera Turbo`, `Sunburst GT`, `Coastal Cruiser`), evade the police wanted pursuit system, and take on repeatable missions (Smuggler Delivery, Street Race, Cash Drops).

Features custom WebAudio sound effects (engine roar, police sirens, crash impacts, pickups), a live minimap HUD, dynamic pedestrians and traffic AI, and fully responsive arcade vehicle physics.

## Controls

- **WASD / Arrow Keys:** Move on foot / Drive vehicle
- **E:** Enter or Exit vehicle
- **Shift:** Sprint (on foot)
- **Space:** Handbrake (in vehicle)
- **P / Esc:** Pause / Resume game
- **M:** Mute / Unmute audio
